# Security Policy

## Supported scope
Security expectations cover the web app, Supabase integration layer, and deployment configuration.

## Reporting a vulnerability
Please report suspected vulnerabilities privately via GitHub Security Advisories for this repository. Do not disclose active vulnerabilities publicly before triage.

## Security controls currently in repository
- Supabase Row Level Security (RLS) policies for user-scoped data access
- Auth-linked ownership checks in database policies
- Frontend environment variable usage for publishable client config only

## Response expectations
- Initial acknowledgement target: 3 business days
- Triage and remediation priority based on impact and exploitability
